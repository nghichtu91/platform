## planx组件列表

### 组件说明

|名称|功能|备注|
|----|----|----|
|arrayhelper|slice相关辅助函数，包括类型转换、shuffle等|
|battle_check|旧的战斗校验|
|bin|指定版本的protoc和protoc-gen-go|
|client|客户端与gatex/gamex收发包相关|
|cloud_db|云存储接口|
|cmds|github.com/urfave/cli模板|
|codec|github.com/ugorji/go/codec序列化/反序列化|
|config|服务读取配置封装|
|dynamodb|dynamodb封装|
|etcd|etcd封装|
|etcd_ser_discovery|etcd服务发现封装|
|ginhelper|gin相关辅助函数|
|githubsrc|从github拉取后，做了定制化修改的库|
|grpchealth|检查grpc健康度的库|
|hotfix|代码热更|
|ip2location|ip地址转换为国家地区|
|iputil|使用云API获取内网/外网ip|
|limit|流量控制和ip访问控制|
|mergeinfo|管理合服关系|
